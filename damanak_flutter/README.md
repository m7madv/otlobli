# ضمانك للأعمال

تطبيق `Flutter` عربي لإدارة الضمانات والمنتجات وطلبات الصيانة وفرق المتاجر في الخليج.

## الوظائف

- حساب مالك مستقل بالبريد وكلمة المرور مع جلسة محفوظة على الجهاز.
- إنشاء متجر أو الانضمام إلى متجر قائم برمز دعوة مؤقت.
- حساب منفصل لكل موظف مع صلاحيات `owner` و`manager` و`staff`.
- خطط اشتراك وحدود أعضاء وضمانات شهرية مفروضة داخل قاعدة البيانات.
- تفعيل الاشتراك برمز، أو تسجيل طلب اشتراك للتواصل دون ادعاء تنفيذ دفعة وهمية.
- كتالوج منتجات يحفظ الباركود ورمز المخزون ومدة الضمان والسعر الافتراضي.
- ماسح باركود داخل واجهة ضمانك باستخدام كاميرا التطبيق، مع إضاءة وتبديل كاميرا وإدخال يدوي.
- إصدار ضمان من المنتج الممسوح، ومشاركة البطاقة، ورمز تحقق لا يتضمن جوال العميل.
- سجل طلبات صيانة وسجل تدقيق للعمليات المهمة.
- سياسات `RLS` تعزل بيانات كل متجر وتتحقق من الأدوار على الخادم.

## التصميم

- واجهة عربية من اليمين إلى اليسار، مبنية على لون علامة واحد ودرجات حيادية.
- المظهر الفاتح والداكن يتبعان إعداد الجهاز تلقائياً.
- الألوان دلالية، والحالات تعرض أيقونة ونصاً ولا تعتمد على اللون وحده.
- أهداف اللمس العامة لا تقل عن `48dp`، وتُحترم إعدادات تقليل الحركة.
- تقرير المراجعة وفق مهارة `Apple Design`: `../docs/DESIGN_AUDIT.md`.

## البنية

- التطبيق: `lib/`
- مخطط قاعدة البيانات وسياسات الأمان: `supabase/migrations/20260824090000_damanak_core.sql`
- إعداد `Supabase` المحلي: `supabase/config.toml`
- نموذج مفاتيح البناء: `dart-defines.example.json`

قاعدة «ضمانك» يجب أن تكون مشروع `Supabase` مستقلاً. لا تطبق migration على قاعدة تطبيق آخر.

## تشغيل العرض التشغيلي

عند التشغيل بلا مفاتيح تظهر شاشة إعداد تتيح فتح عرض تشغيلي محلي ببيانات نموذجية:

```bash
flutter pub get
flutter run
```

العرض مخصص لفحص الواجهات والمسارات، ولا يزعم وجود حساب سحابي.

## تشغيل النظام السحابي

1. أنشئ مشروع `Supabase` جديداً.
2. اربط المجلد بالمشروع الجديد فقط.
3. طبّق migration:

```bash
supabase link --project-ref YOUR_NEW_PROJECT_REF --workdir damanak_flutter
supabase db push --workdir damanak_flutter
```

4. انسخ `dart-defines.example.json` إلى `dart-defines.json` وضع رابط المشروع والمفتاح القابل للنشر. الملف الحقيقي مستثنى من `Git`.
5. شغّل التطبيق:

```bash
flutter run --dart-define-from-file=dart-defines.json
```

وبناء Android:

```bash
flutter build apk --release --dart-define-from-file=dart-defines.json
```

## الاشتراك

النظام يوفّر تجربة 14 يوماً، ثم يفرض حالة الاشتراك والحد الشهري للضمانات وعدد أعضاء الفريق من قاعدة البيانات. يوجد مساران للتفعيل:

- رمز تفعيل يُنشئه مشرف المنصة ويبيعه أو يرسله للمتجر.
- طلب اشتراك يسجَّل للمراجعة والتواصل.

ربط دفع إلكتروني مباشر يحتاج حساب تاجر واختيار بوابة متوافقة مع دولة الإطلاق ومتطلبات متاجر التطبيقات. لم يُضف تحصيل وهمي أو مفتاح سري داخل تطبيق الجوال.

لإنشاء رمز تفعيل من `SQL Editor` في بيئة الإدارة:

```sql
with generated as (
  select 'DMN-CHANGE-ME'::text as raw_code
)
insert into public.activation_codes (
  code_hash,
  plan_id,
  duration_days,
  max_uses,
  expires_at
)
select
  extensions.digest(upper(raw_code), 'sha256'),
  'growth',
  365,
  1,
  now() + interval '30 days'
from generated;
```

استبدل الرمز قبل التنفيذ، وأرسله للعميل عبر قناة آمنة.

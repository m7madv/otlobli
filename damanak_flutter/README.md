# ضمانك

تطبيق `Flutter` عربي لإدارة بطاقات الضمان الرقمية وطلبات الصيانة لدى المتاجر الصغيرة.

## ما الذي يقدمه؟

- إنشاء بطاقة ضمان باسم العميل والمنتج ومدة الضمان.
- حساب تاريخ الانتهاء وحالة الضمان تلقائياً.
- البحث والتصفية بين الضمانات السارية والقريبة من الانتهاء والمنتهية.
- مشاركة بطاقة نصية مع العميل وعرض رمز `QR` محلي للتحقق.
- تسجيل طلبات الصيانة وتحديث حالتها.
- حفظ بيانات المتجر والضمانات على الجهاز باستخدام `SharedPreferences`.

## التشغيل

```bash
flutter pub get
flutter run
```

ولإنشاء ملف تجريبي لنظام Android:

```bash
flutter build apk --debug
```

## الخصوصية والتكلفة

الإصدار الحالي لا يحتاج إلى خادم أو حساب مستخدم أو خدمة مدفوعة. تبقى البيانات محلياً على الجهاز. حذف التطبيق أو بياناته قد يؤدي إلى فقدان السجلات، لذلك يُنصح بمشاركة البطاقات المهمة والاحتفاظ بها خارج التطبيق.

## حدود الإصدار الأول

- لا توجد مزامنة بين عدة أجهزة.
- رمز `QR` يحمل بيانات تحقق محلية ولا يفتح صفحة عامة على الإنترنت.
- إصدار iOS يحتاج إلى جهاز `macOS` وبيئة `Xcode` للتوقيع والبناء النهائي.

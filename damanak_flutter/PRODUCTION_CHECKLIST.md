- [x] الاشتراك التجريبي والخطط والحدود ورموز التفعيل وطلبات الاشتراك.
- [x] ماسح باركود خاص بالتطبيق وإدخال يدوي ومطابقة كتالوج المتجر.
- [x] المنتجات والتصنيفات والأسعار ومدد الضمان والتعديل والأرشفة.
